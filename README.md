## 記録のルール

引用、文献情報、調査結果は実際に確認したものだけを記載します。出典のある内容と自分の考えを区別し、未確認の内容にはその旨を付けます。

このリポジトリは準備時点で公開設定です。調査協力者の個人情報や、公開許可のない資料は掲載しません。

## ファイルと作業方法

- [AGENTS.md](AGENTS.md)：執筆・文献確認・保存・ログのルール
- [REFERENCES.md](REFERENCES.md)：ユーザー提示の参考文献候補8件と確認状況
- [WORK_LOG.md](WORK_LOG.md)：各回の詳しい作業ログ

ファイルは作業環境内で編集し、変更点とログを確認してからコミット・プッシュします。

## WordとPDF

- [thesis.docx](thesis.docx)：本文の正本。現段階は研究準備版。
- [thesis.pdf](thesis.pdf)：同じWordから出力した閲覧用PDF。

更新のたびにWordとPDFをそろえて確認し、作業ログと一緒にプッシュします。大学の執筆資料を受領後に指定の構成・書式に合わせます。

- [build_document.py](build_document.py)：初期の準備版の生成用。Wordの直接編集を消さないよう、通常の更新では再実行しません。
- [.gitignore](.gitignore)：Wordの一時ファイルや確認用画像等の除外設定。

閲覧用のPDFとWordは、会話内で直接開けるファイルとして提示します。GitHubは保存先として引き続き利用します。

- [previews/](previews/)：PDFの各ページの閲覧用画像。iPhone等でファイルを開けない場合に会話内で表示する補助版です。
