# 卒業論文の執筆ノート

研究計画、章立て、文献メモを整理するための出発点です。未確定の項目は、確認できた内容から記入します。

## 提出条件

- 提出期限：未確認
- 必要な文字数・ページ数：未確認
- 大学・ゼミの書式と引用方法：未確認

## 研究計画

- テーマ・仮タイトル：未定
- 関心を持った理由：未記入
- 明らかにしたいこと（研究の問い）：未定
- 対象とする年齢・場面・範囲：未定
- 研究方法：未定（指導教員と相談して決める）

## 章立ての仮案

研究方法と大学の指定に合わせて変更します。

1. 序論：研究の背景、問題意識、目的
2. 先行研究の整理：これまでに分かっていることと課題
3. 研究方法：資料の選定方法、または調査・分析の方法
4. 結果：文献の整理結果、または調査結果
5. 考察：研究の問いに対する解釈と研究の限界
6. 結論：明らかになったことと今後の課題
7. 参考文献

## 文献メモのひな形

- 著者・発行年：
- 論文名・書名：
- 掲載誌・巻号・ページ／出版社：
- URL・DOI（ある場合）：
- 読んだ日：
- 研究目的・対象・方法：
- 主な結果と著者の主張（自分の言葉で要約）：
- 引用したい箇所とページ：
- 自分の考え・卒論とのつながり：

## 最初の作業

- [ ] 提出期限・分量・書式を確認する
- [ ] テーマ候補を整理する
- [ ] 研究の問いを一文にする
- [ ] 関連する先行研究を探し、実際に読む
- [ ] 研究計画を指導教員に相談する
- [ ] 章立てを調整して本文を書き始める

## 記録のルール

引用、文献情報、調査結果は実際に確認したものだけを記載します。出典のある内容と自分の考えを区別し、未確認の内容にはその旨を付けます。

このリポジトリは準備時点で公開設定です。調査協力者の個人情報や、公開許可のない資料は掲載しません。
