# 卒業論文の執筆ノート

研究計画、章立て、文献メモを整理するための出発点です。未確定の項目は、確認できた内容から記入します。

## 提出条件

- 提出期限：未確認
- 分量：図表・目次・文献を含む約17ページ。20,000字は目安であり、本文のみで到達させる必要はありません。
- 書式：A4縦・横書き、40字×30行、10.5ポイント、本文MS 明朝。見出しの正式フォント名と引用様式の細部は要確認。

## 研究計画

- テーマ：乳幼児期におけるデジタルメディアの利用と子どもの発達との関連
- 関心を持った理由：未記入
- 明らかにしたいこと（研究の問い）：未定
- 対象とする年齢・場面・範囲：未定
- 研究方法：文献研究
- 大学の執筆要項：2026年11月18日に文字起こしを受領。[執筆条件の整理](THESIS_REQUIREMENTS.md)を参照。

## 章立ての仮案

研究方法と大学の指定に合わせて変更します。

1. はじめに：テーマを取り上げた理由（本人の動機は要確認）
2. 第1章　問題と目的：背景、先行研究、目的と意義
3. 第2章　方法：調査時期と対象文献、検索・選定の手順
4. 第3章　結果：運動発達と能力、睡眠、親との愛着関係、言語・コミュニケーション
5. 第4章　総合考察：目的の再提示、総括、考察、今後の課題
6. おわりに
7. 文献

大学の指定を基にした仮構成です。現在は6ページの中間稿であり、17ページの完成稿ではありません。配分の仮案はTHESIS_REQUIREMENTS.mdを参照します。

## 記録のルール

引用、文献情報、調査結果は実際に確認したものだけを記載します。出典のある内容と自分の考えを区別し、未確認の内容にはその旨を付けます。

このリポジトリは準備時点で公開設定です。調査協力者の個人情報や、公開許可のない資料は掲載しません。

## ファイルと作業方法

- [AGENTS.md](AGENTS.md)：執筆・文献確認・保存・ログのルール
- [REFERENCES.md](REFERENCES.md)：ユーザー提示8件と追加の学術2件（計10件）の確認状況

## WordとPDF

- [thesis.docx](thesis.docx)：本文の正本。現段階は方法・結果の中間稿。
- [thesis.pdf](thesis.pdf)：同じWordから出力した閲覧用PDF。

更新のたびにWordとPDFをそろえて確認し、作業ログと一緒にプッシュします。受領した2026年度の要項に沿って構成・書式を整えます。

- [build_document.py](build_document.py)：初期の準備版の生成用。Wordの直接編集を消さないよう、通常の更新では再実行しません。
- [.gitignore](.gitignore)：Wordの一時ファイルや確認用画像等の除外設定。

閲覧用のPDFとWordは、会話内で直接開けるファイルとして提示します。GitHubは保存先として引き続き利用します。

- [previews/](previews/)：PDFの各ページの閲覧用画像。iPhone等でファイルを開けない場合に会話内で表示する補助版です。

## 出典の方針

一般のウェブ検索を使わず、論文本文に基づいて執筆します。補足資料が必要な場合は厚生労働省・文部科学省などの公的機関の一次資料に限ります。一般記事・ブログ・ニュース等は根拠にしません。既存論文の本文はDOIや学術データベース等の掲載先から直接確認します。
